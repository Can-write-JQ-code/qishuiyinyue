# 汽水音乐「看视频领会员」机制调研与自动化实现方案整理

> 本文档仅供个人技术学习与无障碍自动化研究参考，严禁用于商业分发或破坏平台正常运营秩序。

## 第一部分：汽水音乐「看视频得会员」产品与商业机制

### 1. 权益本质
用户在汽水音乐通过看视频获得的并非完整付费 VIP，而是官方协议定义的 **「限时免费畅听权益」**（辅以签到/活动赠送的短期体验卡），本质是字节系成熟的 **IAA（激励视频广告变现）+ IAP（双层会员订阅）** 混合变现模型。

### 2. 触发入口与解锁规则
* **三大入口**：
  1. **主动入口**：首页/播放页顶部常驻 **「免」字图标 /「免费听」按钮**（直接拉起 15～30 秒穿山甲激励广告）。
  2. **被动拦截**：上下滑切歌刷到 VIP 曲目试听结束时，弹窗提示「看视频免费听」。
  3. **任务体系**：底部【福利】页签到（如满 7 天兑体验卡）、看广告开宝箱攒金币（约 `33000 金币 ≈ 1 元`，可提现或兑畅听卡）。
* **阶梯式时长与动态调控**：
  * **二段激励**：看 1 个视频通常解锁 **30 分钟～1 小时**；播完后常弹出 **「再看一个，解锁全天（至当日 24:00）免费畅听」**。
  * **千人千面门槛**：轻度用户通常看 **2 个视频（约 60～80 秒）** 解锁全天；长期高频未付费用户会被算法动态上调至 **3 个或更多视频**。

### 3. 权益对比与隐性限制

| 维度 | 看视频免费畅听 | 付费 VIP（约 8元/月） | 付费 SVIP（约 18元/月） |
| :--- | :--- | :--- | :--- |
| **普通 VIP 曲库** | ✅ 在线完整播放 | ✅ 完整播放 | ✅ 完整播放 |
| **SVIP 专属音源** | ❌ 无法解锁（仅翻唱/试听） | ❌ 部分原版受限 | ✅ 全部解锁 |
| **最高音质** | 标准（AAC 128kbps） | 无损（FLAC） | Hi-Res 高解析度无损 |
| **离线下载缓存** | ❌ 不支持 | ✅ 约 300 首/月 | ✅ 无限制下载 |
| **免广告范围** | 仅免听歌拦截（仍有信息流/开屏广告） | 免常规广告 | 全场景免广告 |
| **多端与车机** | 仅基础流媒体 | 手机/PC/平板通用 | 含**车机端特权** + 家庭共享 |

### 4. 底层商业逻辑
* **广告收益算得过账**：汽水音乐超 70%～80% 流量源自抖音导流，用户对短视频广告耐受度与点击率高；每天看 2～3 条激励视频产生的 eCPM 广告收益，足以媲美甚至高于 8 元月卡（日均约 0.26 元）的分摊收入。
* **矩阵分工**：字节通过**番茄音乐**承接下沉/中老年市场（纯免费+重度赚金币），通过**汽水音乐**承接年轻群体（看视频畅听托底做大月活，靠音质、下载、车机与 SVIP 原版音源筛选高价值付费用户）。

## 第二部分：Android 端自动化工具工程落地要点

### 1. 技术选型
* **Kotlin + `AccessibilityService`（Android 11+ `takeScreenshot`）+ Google ML Kit 本地中文 OCR**。
* 采用 **「空白通用状态机引擎 + 本地可编辑关键词规则」** 分离架构，既能应对汽水音乐界面微调，也遵循个人研究工具合规边界。

### 2. 核心状态机流程（目标包名 `com.luna.music`）
1. **寻址启动**：启动目标应用 $\rightarrow$ 检测是否已解锁「全天畅听」（已解锁则结束） $\rightarrow$ 点击顶部「免/免费听」或弹窗「看视频免费听」。
2. **容器接管**：识别进入激励视频页（如 `ExcitingVideoActivity` / `TTRewardVideoActivity` 或广告倒计时标识） $\rightarrow$ 通过系统 `AudioManager` 将媒体音量备份并临时静音。
3. **倒计时守护与防误跳**：轮询等待 15～35 秒直至出现「领取成功 / 奖励已领取」；期间若误触摇一摇跳出应用或跳入直播间/内置网页，立即触发全局 `Back` 拉回广告页。
4. **连看与收尾**：出现「再看一个 / 继续观看」优先点击续看；无续看弹窗则关闭广告返回主页复核是否拿满当日时长，最后恢复原媒体音量。
5. **终止兜底**：检测到「当前无新视频 / 暂无视频」或超时（>65 秒），自动中止、恢复音量并通知用户。
