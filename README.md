# 汽水音乐自动看广告领畅听小助手（安卓版）

这是一个装在**安卓手机**上的独立小工具，专门用来帮你自动刷汽水音乐里的「看广告领免费听歌时长」。

平时在汽水音乐里攒免费听歌天数，得自己盯着屏幕等二三十秒、手动点右上角关闭、再点继续看下一条，不仅麻烦，广告声音还吵，稍微晃一下手机就容易跳去淘宝京东。

**装上这个小工具后：**
你只要点一下开始，把手机放桌上——它会自动把手机先静音，帮你把广告一条接一条看完、把免费听歌时长领到手，全部领完后再自动把手机音量调回原来的大小。

> **省心特点**：完全在手机本地运行，**不用连电脑、不用买蓝牙外设、也不用花钱填任何 AI 接口密钥**，装上就能直接免费用。

## 它能帮你做什么？

- **看广告自动静音，看完自动恢复**：开始前自动把手机媒体声音关掉，不吵人；等全部刷完或者你手动点停止时，自动恢复你原来的音量。
- **开屏广告直接秒跳**：打开汽水音乐遇到开屏广告，看到右上角「跳过」直接帮你点掉。
- **一条接一条无缝连看**：不用退回主页重进，看完一条自动点右上角「领取成功」，接着马上点弹窗中间的「领取奖励」直接看下一条。
- **想看几条随你定（支持刷满当天上限）**：可以自己设看几条（比如看 4 条攒两天），也可以把 **「无限循环模式」** 打开，让它一直看到今天平台不给新广告为止，自己停下收工。
- **遇到直播间广告也能领，绝不乱点关注**：刷到直播间形式的广告时，它只会点最右上角的叉把直播关掉（**绝对不会去碰左边的主播头像和「关注」按钮**），关掉直播后照样帮你把这轮时长领到手。
- **随时能开始、随时能喊停**：屏幕左边有个小巧的悬浮按钮，在汽水音乐里随时点绿色 `▶ 启动` 就能接着刷；你想用手机了，点一下红色 `■ 停止` 立马停手并恢复声音。

## 它是怎么干活的？（大白话流程）

核心思路参考了开源项目 [qishuiAScriptProject](https://github.com/wei6718189/qishuiAScriptProject)，把复杂的判断简化成了最稳当的固定动作：

```text
打开汽水音乐 + 自动把手机调成静音
    ↓
右上角有「跳过」就顺手点掉开屏广告
    ↓
自动点进第 1 条广告（点「免费听 / 领时长 / 右上角金币」）
（就算某天汽水音乐首页改版没自动点进去，你随手点开第 1 条广告，后面它也会自动接手）
    ↓
┌────────────────────────────────────────────────────────┐
│                   自动连看循环开始                      │
│                                                        │
│  1. 等广告倒计时走完（如果是直播间广告就点最右上角关掉） │
│          ↓                                             │
│  2. 看到右上角变成「领取成功 ×」，点它一下              │
│          ↓                                             │
│  3. 屏幕正中间弹出窗口：                                │
│     • 还没看够次数 → 点绿色的「领取奖励」直接看下一条   │
│     • 已经看够次数 → 点下面的「坚持退出」收工回家       │
│                                                        │
│  如果提示「当前无新视频」（今天额度领完了）→ 自动停下   │
└────────────────────────────────────────────────────────┘
    ↓
把手机音量调回原来的大小，搞定！
```

而且它看屏幕的时候**只看关键的一小块地方**（比如只看右上角有没有「领取成功」、只看屏幕正中间有没有「领取奖励」），反应特别快，也**绝对不会误点屏幕底下那些「立即下载」的广告按钮**。

## 怎么下载和使用？（只需 3 步）

支持 **安卓 11 及以上** 的手机。

### 第一步：下载安装
去本仓库的 [**Releases 下载页面**](https://github.com/Can-write-JQ-code/qishuiyinyue/releases)，点最新的 `qishui-ad-helper-debug.apk` 下载安装到手机上。

### 第二步：第一次打开先开好权限（只用设这一次）

1. **打开「无障碍服务」（必开）**：
   - 进软件点第 1 项右边的 **「去开启」**，在列表里找到 **「畅听自动化无障碍引擎」** 打开。
   - **如果开关是灰色的点不动（提示“受限设置”）**：这是新安卓系统对非应用商店软件的常规保护，解开很简单：
     1. 先点一下那个灰色开关让它弹一次提示；
     2. 回到本软件，点右上角 **「受限设置说明 -> 打开本应用详情页」**；
     3. 点页面右上角的三个点 `⋮` $\rightarrow$ 选 **「允许受限设置」**；
     4. 再回刚才的无障碍列表，就能正常打开了！
2. **打开「悬浮窗」和「省电白名单」（建议打开）**：
   - 把首页第 2、3 项也点亮，这样小浮窗能正常显示，看广告中途也不会被手机省电功能偷偷关掉。
3. **防摇一摇乱跳购物软件（强烈建议顺手设一下）**：
   - 在手机桌面上长按「汽水音乐」图标 $\rightarrow$ 点「应用信息」$\rightarrow$「权限管理」：
   - 把 **「获取设备动作与方向」**（陀螺仪摇一摇）和 **「打开其他应用」** 都改成 **拒绝**。这样广告再怎么诱导摇一摇，也跳不出去了。
4. **小米 / 澎湃 / vivo / OPPO 手机额外看一眼**：
   - 如果待会儿运行发现软件提示“已点击”但屏幕没动静，去手机系统「开发者选项」里把 **「USB 调试（安全设置）」**（OPPO 叫「禁止权限监控」）打开即可。

### 第三步：开始刷时长（两种用法挑顺手的）

- **用法一：懒人一键全自动**
  在本软件里填好你想连看几轮（或者直接打开 **「无限循环模式」** 开关），点大按钮 **「一键启动极速连看」**，它自己就会打开汽水音乐开始干活。
- **用法二：挂小浮窗随时接管**
  点 **「挂起悬浮窗（在汽水内点 ▶ 接管）」**，你自己去汽水音乐里，不管是停在首页、福利页，还是已经点开了第一条广告，随时点一下屏幕左边小浮窗上的绿色 **`▶ 启动`**，它就立刻接手往下连看。

## 常见问题解答

| 遇到什么情况 | 是怎么回事 | 怎么解决 |
| :--- | :--- | :--- |
| 无障碍开关是灰色的打不开 | 新安卓系统的侧载安全保护 | 到本软件的「应用详情页」点右上角 `⋮` $\rightarrow$ 选「允许受限设置」，再回去开就行 |
| 日志里写了“点击”但画面没反应 | 手机系统拦住了模拟点击 | 去手机「开发者选项」里打开「USB 调试（安全设置）」或「禁止权限监控」 |
| 覆盖安装新版本后感觉没变化 | 旧版本的无障碍服务还在后台跑 | 去系统无障碍设置里，把本软件的服务关一下再重新打开一次就刷新了 |
| 看广告时老是跳去淘宝、拼多多 | 广告利用手机传感器触发了摇一摇 | 在系统设置里把汽水音乐的「设备动作与方向」和「打开其他应用」权限关掉 |
| 刷了几条自己停了，说没视频 | 今天汽水音乐给你的免费广告额度用完了 | 正常现象，平台每天可看的激励视频有上限，第二天会自动恢复 |

## 想自己改代码或重新打包？

- **云端自动打包（不用装开发环境）**：只要修改代码推送到 GitHub 的 `main` 分支（或在仓库 **Actions** 页面手动点 `Run workflow`），等一分半钟就会自动编译好新的安装包发到 **Releases** 里。
- **电脑本地打包**：电脑装好 Android Studio 打开本项目文件夹，插上手机点绿色运行按钮即可。
