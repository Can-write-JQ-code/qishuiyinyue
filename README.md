# 畅听自动化助手 v2.0 (`qishui-ad-helper`)

基于 **Kotlin + Android `AccessibilityService` (API 30+ 静默截屏) + 局部小区域裁剪 ML Kit 离线中文 OCR** 构建的独立原生 Android 自动化工具。

v2.0 核心流程吸收了 [wei6718189/qishuiAScriptProject](https://github.com/wei6718189/qishuiAScriptProject) 的五阶段精简设计，并原生适配 Android 端汽水音乐（`com.luna.music`）：

```text
启动汽水音乐 + 系统自动静音
    ↓
阶段一：右上角小区域极速扫描跳过开屏广告
    ↓
阶段二 & 三：[自动进首条广告（免费听胶囊 / 提前领 / 领时长 / 右上金币）] 或 [手动进首条广告无缝接管]
    ↓
┌────────────────────────────────────────────────────────┐
│               核心两步确定性连看循环                    │
│                                                        │
│  阶段四：等待倒计时结束                                │
│    ├─ 视频广告：盯右上角等「领取成功」出现             │
│    └─ 直播间广告：关右上角 × → 等右上角「领取成功」    │
│          ↓                                             │
│  阶段五 - 步骤 1/2：点右上角「领取成功 ×」             │
│          ↓                                             │
│  阶段五 - 步骤 2/2：紧盯中间弹窗点「领取奖励」→ 下一轮 │
│                   （看满目标轮数则点「坚持退出」收尾） │
│                                                        │
│  结束自动恢复原系统媒体音量                            │
└────────────────────────────────────────────────────────┘
```

---

## 核心优势

1. **局部百分比区域裁剪 OCR (`PctRegion` + `ScreenOcrHelper`)**：
   - 不再全屏大图跑 OCR，而是按屏幕百分比仅裁剪目标小区域（如右上角 `AD_CLAIM_TOP`、正中间 `AD_REWARD_MODAL`、开屏右上角 `SPLASH_SKIP`）送入离线 OCR，识别耗时降至 **30～50ms**，且物理隔绝底部「立即下载」诱导按钮。
2. **确定性两步连看闭环 (`claimRewardTwoStep`)**：
   - 摒弃复杂易串状态的全局重猜，点完右上角「领取成功 ×」后立即以 `0.38s` 高频紧盯中间弹窗区，秒点「领取奖励」无缝切入下一轮广告。
3. **视频广告 + 直播间广告双支持**：
   - 遇到直播间激励广告自动点右上角关闭（及「退出不看了」二次确认），关闭后继续等待右上角吐出「领取成功」正常领奖。
4. **指定轮数 / 无限刷满当日额度双模式 + 自动静音恢复**：
   - 支持指定连看 `1～50` 轮，或开启「无限循环模式」刷到当日无新视频自动停止，全程自动备份并恢复系统媒体音量。
