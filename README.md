# 汽水音乐 Android 畅听自动化助手 (`qishui-ad-helper`)

基于 **Kotlin + Android `AccessibilityService`（API 30+ 静默截屏）+ Google ML Kit 离线中文 OCR** 构建的原生 Android 独立自动化应用，用于自动观看汽水音乐（`com.luna.music`）激励广告以领取免费畅听时长。

> **纯本地脱机运行**：无需连接电脑 ADB、无需外接蓝牙硬件、无需配置任何付费大模型 API Key，直接安装到 Android 11+ 手机即可独立运行。

---

## 功能特性

- **自动启动与开屏秒跳**：自动拉起汽水音乐，右上角局部高频扫描精准跳过开屏广告。
- **系统级媒体音量守护**：启动任务自动备份当前媒体音量并切换为系统静音；任务完成、手动停止或异常退出时自动恢复原音量。
- **确定性两步连看闭环**：倒计时结束后执行确定性两步点击（点右上角「领取成功 ×」$\rightarrow$ 紧盯中间弹窗点「领取奖励」），在广告容器内无缝切入下一轮广告。
- **视频广告 + 直播间广告双支持**：
  - **视频广告**：自动等待倒计时归零出现「领取成功」；中途若误触暂停弹窗自动点中间区「继续观看」恢复。
  - **直播间广告**：识别到直播间特征后仅点击最右上角关闭按钮（及「退出不看了」确认），**绝不检索或触碰主播「关注」按钮**，关闭后继续等待右上角吐出「领取成功」正常领奖。
- **局部小区域裁剪 OCR + 节点快检双引擎**：优先走 `<2ms` 多窗口无障碍节点匹配；节点未暴露时仅裁剪目标百分比小区域送入离线中文 OCR（单次耗时仅 `30～50ms`），物理隔绝底部「立即下载」诱导区。
- **双运行模式 & 悬浮胶囊接管**：
  - 支持设定固定连看次数（`1～50` 轮），或开启 **「无限循环模式」** 一直刷到当日额度耗尽（「当前无新视频」）自动退出；
  - 支持一键全自动运行，也支持挂起可拖动迷你悬浮窗，在汽水音乐任意页面点击 `▶ 启动` 就地接管、点击 `■ 停止` 随时急停。

## 核心执行流程

核心流转借鉴了 [wei6718189/qishuiAScriptProject](https://github.com/wei6718189/qishuiAScriptProject) 的五阶段精简设计，并针对 Android 端 `com.luna.music` 进行了原生适配与像素校准：

```text
启动汽水音乐 + 备份媒体音量并系统静音
    ↓
阶段一：右上角小区域高频扫描跳过开屏广告
    ↓
阶段二：检测底部续费会员弹窗（「元开通」）→ 点击上方遮罩关闭
    ↓
阶段三：[自动进入第 1 条广告（提前领 / 领时长 / 免费听胶囊 / 右上金币）]
        或 [未命中时不报错退出，等待用户手点任意广告后立即无缝接管]
    ↓
┌──────────────────────────────────────────────────────────────┐
│                     核心两步确定性连看循环                    │
│                                                              │
│  阶段四：等待广告倒计时结束                                   │
│    ├─ 视频广告：盯右上角等「领取成功 / 奖励已领取」出现       │
│    └─ 直播间广告：点最右上角 × 关闭 → 等右上角「领取成功」    │
│          ↓                                                   │
│  阶段五 - 步骤 1/2：点击右上角「领取成功 ×」                  │
│          ↓                                                   │
│  阶段五 - 步骤 2/2：停 0.55s 后高频紧盯正中间弹窗区           │
│    ├─ 未满目标轮数：点击「领取奖励」→ 直接无缝进入下一轮广告  │
│    └─ 已满目标轮数：点击「坚持退出」→ 干净离开广告容器        │
│                                                              │
│  检测到「当前无新视频」或连续空闲达上限 → 自动收尾退出        │
└──────────────────────────────────────────────────────────────┘
    ↓
自动恢复原系统媒体音量 + 关闭前台通知
```

## 技术栈与模块分工

| 模块 / 类 | 技术方案与职责 |
| :--- | :--- |
| `AdHelperAccessibilityService` | 多窗口穿透无障碍节点检索（`windows` + `rootInActiveWindow`）、Android 11+ `takeScreenshot` 静默截屏、拟人随机偏移手势派发（失败自动回退节点 `ACTION_CLICK`） |
| `ScreenOcrHelper` | 基于 `PctRegion` 的局部 Bitmap 裁剪 + Google ML Kit 离线中文识别（`text-recognition-chinese`）+ 形近字纠偏与胶囊子框切分 |
| `TaskStateMachine` | 五阶段主流程与确定性两步领取循环控制、外跳应用/落地页拦截拉回 |
| `VolumeGuard` | `AudioManager` 媒体流音量持久化备份与异常安全恢复 |
| `FloatingOverlayManager` | `TYPE_APPLICATION_OVERLAY` 左上无遮挡悬浮胶囊（`▶ 启动 / ■ 停止 / ×`），按区域重叠智能隐身零闪烁 |
| `KeepAliveForegroundService` | Android 14+ `specialUse` 常驻前台通知保活与通知栏一键停止 |

## 动态百分比 ROI 识别区域设计

所有视觉裁剪与节点搜索区域均按**屏幕宽高百分比动态计算**，自适应不同分辨率与屏幕比例的 Android 设备：

| 区域常量 | 坐标比例范围 (`x`, `y`) | 用途与防误触设计意图 |
| :--- | :--- | :--- |
| `SPLASH_SKIP` | `x: 70%~98%`, `y: 4%~14%` | 仅扫描开屏广告右上角「跳过」按钮 |
| `AD_CLAIM_TOP` | `x: 54%~99%`, `y: 2.5%~13.5%` | 激励广告右上角「领取成功 ×」与倒计时专属区 |
| `AD_REWARD_MODAL` | `x: 12%~88%`, `y: 25%~71%` | 居中弹窗「领取奖励 / 坚持退出 / 继续观看」专属区，物理隔离顶部残留字与底部下载诱导按钮 |
| `LIVE_MORE_TOP_RIGHT` | `x: 66%~98%`, `y: 8%~16%` | 直播间右上角「更多直播」特征识别 |
| `LIVE_CLOSE_TOP_RIGHT` | `x: 86%~99%`, `y: 4%~12%` | 严格限制在直播间最右上角关闭按钮区，彻底远离左侧主播头像与「关注」按钮 |
| `MEMBERSHIP_PAY_BOTTOM` | `x: 4%~96%`, `y: 85%~97%` | 续费会员半屏弹窗底部「元开通」检测区 |
| `LANDING_DONE_TOP_LEFT` | `x: 1%~22%`, `y: 4%~13%` | 第三方下载落地页左上角「完成」关闭检测区 |

## 快速开始（手机端安装与配置）

### 1. 环境要求与下载
- **系统版本**：Android 11（API 30）及以上真机。
- **下载安装包**：前往仓库 [**Releases 页面**](https://github.com/Can-write-JQ-code/qishuiyinyue/releases) 下载最新的 `qishui-ad-helper-debug.apk` 安装到手机。

### 2. 首次使用必做权限配置（仅需一次）

1. **开启无障碍服务（解除 Android 13/14/15/16「受限设置」）**：
   - 打开本应用，点击首页第 1 项右侧 **「去开启」**；
   - 若系统无障碍列表中开关呈灰色并提示「受限设置」：
     1. 先点一下灰色条目触发系统提示；
     2. 返回本应用点击右上角 **「受限设置说明 -> 打开本应用详情页」**；
     3. 点击应用详情页右上角 `⋮` 菜单 $\rightarrow$ 选择 **「允许受限设置」**；
     4. 再回系统无障碍列表开启 **「畅听自动化无障碍引擎」**（每次覆盖升级新版本后，建议将无障碍开关重开一次以确保新进程生效）。
2. **开启模拟点击底层权限（小米/澎湃/vivo/OPPO 必查）**：
   - 进入手机「开发者选项」，确认同时开启 **「USB 调试（安全设置）」** 或 **「禁止权限监控」**，否则系统可能拦截手势点击。
3. **封堵汽水音乐摇一摇外跳权限（强烈建议）**：
   - 长按桌面「汽水音乐」图标 $\rightarrow$ `应用信息 -> 权限管理`：将 **「获取设备动作与方向」** 与 **「打开其他应用 / 后台弹出界面」** 设为**拒绝**，从系统层拦截绝大部分摇一摇跳转。
4. **开启悬浮窗与省电白名单**：
   - 在本应用首页依次授权「悬浮窗胶囊」与「后台省电白名单」。

### 3. 运行方式（二选一）

- **方式一：全自动一键运行**
  设定「连看次数」（或打开「无限循环模式」），直接点击 **「一键启动极速连看」**，工具会自动拉起汽水音乐并完成后续全部流程。
- **方式二：悬浮窗就地接管**
  点击 **「挂起悬浮窗（在汽水内点 ▶ 接管）」**，手动打开汽水音乐停在任意页面（首页、福利页或已点开的广告页），点击屏幕左侧悬浮胶囊上的绿色 **`▶ 启动`** 即可立即接管连看；想随时中断点击红色 **`■ 停止`** 即可恢复原音量并停机。

## 自行编译构建

### 方式 A：Android Studio 本地构建
1. 安装 [Android Studio](https://developer.android.com/studio)（内置 JDK 17 与 Android SDK）。
2. 打开本工程根目录，等待 Gradle Sync 完成。
3. 连接 Android 11+ 设备，点击 `Run 'app'` 或执行 `./gradlew :app:assembleDebug`，产物位于 `app/build/outputs/apk/debug/app-debug.apk`。

### 方式 B：GitHub Actions 云端自动构建
推送代码变更至 `main` 分支（或在仓库 **Actions** 页面手动触发 `Build Android Debug APK` -> `Run workflow`），约 90 秒后会自动编译并将 `qishui-ad-helper-debug.apk` 发布至仓库 **Releases**。

## 常见问题排查

| 现象 | 常见原因 | 解决方法 |
| :--- | :--- | :--- |
| 无障碍开关呈灰色无法打开 | Android 13+ 侧载应用受限设置保护 | 本应用详情页右上角 `⋮` $\rightarrow$ 点击「允许受限设置」后再开启无障碍 |
| 日志显示已点击但界面没反应 | 国产系统拦截模拟手势 | 开发者选项中开启「USB 调试（安全设置）」或「禁止权限监控」 |
| 覆盖安装新版后行为没变 | 旧版无障碍进程未重启 | 去系统无障碍设置中将本服务关闭再重新打开一次 |
| 看广告途中频繁跳去淘宝/京东 | 触发广告陀螺仪摇一摇 | 在系统应用权限中拒绝汽水音乐的「设备动作与方向」与「打开其他应用」权限 |
| 跑几轮后提示无新视频并停止 | 达到汽水音乐当日激励视频上限 | 属平台正常每日配额限制，次日自动恢复 |
